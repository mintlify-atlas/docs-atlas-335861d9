Leantime connects day-to-day work to longer-term strategy. The Goals module lets you define measurable targets and track progress automatically as tasks are completed. Strategy canvases give you structured templates for common planning exercises — from business model design to risk analysis and team retrospectives — all living alongside the projects and tasks they relate to.

## Goals

Goals in Leantime follow an OKR-style structure. Each goal has a name, a start value, a current value, and an end value. Progress is shown as a percentage, calculated as `(current - start) / (end - start)`.

### Creating a goal

<Steps>
  <Step title="Open Goals">
    Navigate to **Goals** in the project sidebar.
  </Step>
  <Step title="Add a goal">
    Click **Add goal**. Give it a name and set your start, current, and target values.
  </Step>
  <Step title="Choose a reporting mode">
    Select how the goal tracks progress:
    - **Link only** — link tasks to the goal for visibility, but update the current value manually.
    - **Link and report** — current value is calculated automatically from the values of linked child goals.
    - **No link** — a standalone goal updated manually without task connections.
  </Step>
</Steps>

### Linking tasks to goals

Open any task and set the **Goal** field to associate it with an active goal. This creates a visible connection between day-to-day work and strategic outcomes. When reporting mode is set to **Link and report**, the goal's progress updates as child goal values change.

### Goal hierarchy

Goals can be nested. A parent goal can roll up progress from child goals, enabling company-level OKRs to aggregate from team-level goals automatically.

## Strategy canvases

Canvases are structured, collaborative boards built around specific planning frameworks. Each canvas type provides a pre-defined layout of sections. You add items to each section, discuss them with your team, and use the result to inform your project work.

Leantime includes the following canvas types:

<CardGroup cols={2}>
  <Card title="Lean Canvas" icon="lightbulb">
    A one-page business model template. Covers problem, solution, unique value proposition, customer segments, channels, revenue streams, cost structure, key metrics, and unfair advantage.
  </Card>
  <Card title="Business Model Canvas" icon="briefcase">
    The classic Osterwalder Business Model Canvas with nine building blocks: key partners, key activities, key resources, value propositions, customer relationships, channels, customer segments, cost structure, and revenue streams.
  </Card>
  <Card title="SWOT Analysis" icon="chart-simple">
    Map out your project or product's Strengths, Weaknesses, Opportunities, and Threats in a two-by-two grid.
  </Card>
  <Card title="Risk Analysis" icon="triangle-exclamation">
    Identify and document risks, assess likelihood and impact, and track mitigation actions.
  </Card>
  <Card title="Empathy Map" icon="heart">
    Understand your users by mapping what they think, feel, say, and do. Useful for product discovery and persona development.
  </Card>
  <Card title="Retrospectives" icon="rotate-left">
    A structured template for team retrospectives. Capture what went well, what didn't, and what you want to change going forward.
  </Card>
  <Card title="Value Canvas" icon="star">
    Align your product's value proposition with customer jobs, pains, and gains.
  </Card>
  <Card title="Insights Canvas" icon="magnifying-glass">
    Document research insights, patterns, and findings in a structured format to share with your team.
  </Card>
</CardGroup>

## Working with canvases

All canvas types follow the same basic workflow:

<Steps>
  <Step title="Open the canvas">
    Find the canvas type in the **Strategy** section of the sidebar, or navigate to it from the project menu.
  </Step>
  <Step title="Add items">
    Click the **+** button in any section to add a new item. Give it a title and an optional description.
  </Step>
  <Step title="Edit and organize">
    Click any item to edit its content. You can reorder items within a section by dragging them.
  </Step>
  <Step title="Collaborate">
    All changes are visible to anyone with access to the project in real time. Use comments on individual items to discuss specifics.
  </Step>
</Steps>

<Tip>
  Canvases are project-scoped. Each project can have its own set of canvases, so your Lean Canvas for one product doesn't mix with another.
</Tip>

## Linking strategy to projects and tasks

The connection between strategy and execution happens through goals. When you define a goal tied to a canvas item — for example, a key metric from your Lean Canvas — and then link tasks to that goal, you create a traceable path from strategic intent to daily work.

Use the **Goals** section on any project dashboard to see which goals are on track and which need attention.
